オトリヒキノート🤝

交換・譲渡・買取を、ひとまとめに。
X（旧Twitter）などでのお取引状況を、ブラウザで手軽に管理できる無料のWebアプリです。

オトリヒキノートを使う 使い方を見る

こんなアプリです

🔒ブラウザ内に保存

登録した取引データは端末のブラウザ内に保存されます。制作者側のサーバーへ送信・保存されません。

💰完全無料・広告なし

利用料金はかかりません。画面を邪魔する広告も導入予定はありません。

📦進捗をひと目で管理

取引状況や発送・支払いの進捗を一覧で確認。完全に完了した取引はArchiveへ整理できます。

💾バックアップ対応

データの書き出し・読み込みに対応。機種変更時の移行や万が一の備えに使えます。

「進行中」「完了」「Archive」について

「進行中」は、まだ発送・受け渡し・支払いなどの対応が残っているお取引です。普段は進行中のお取引を中心に確認します。


「完了」は、お取引自体は終わっているものの、まだ一覧に残しておきたい場合に使います。


「Archive」は、確認の必要がなくなった過去のお取引を整理するための場所です。
完了したお取引をArchiveへ移すことで、普段の一覧をすっきり保てます。

3進捗を更新する

「DM確認中」「発送待ち」「完了」など、進行状況に合わせてステータスを変更できます。取引編集画面だけでなく、一覧から直接切り替えることもできます。

住所交換済み🏠・支払い済み💰にチェックを入れると、一覧カードにも絵文字バッジが表示されます。

4完了した取引を整理する

普段は「進行中」の取引だけを表示して、対応が必要なものに集中できます。完了した取引は「完了」表示やArchiveへ移して整理できます。

5イベント表示

🎪を押すとイベント表示モーになります。

イベント当日に、手渡しのお取引だけをまとめて確認しやすくするためのモードです。

イベント表示に切り替えると、手渡しのお取引だけが当日確認しやすい簡易表示になります。「受け渡し済み」ボタンから、完了したお取引をその場ですぐにチェックできます。

また、イベント表示中に新しい取引を登録した場合は、受け渡し方法が自動で「手渡し」に設定されます。

6長期お取引表示

📌を押すと長期お取引表示モードになります。

長発売前・予約商品など、完了まで時間がかかるお取引をまとめて管理するためのモードです。

長期取引には「予定年・予定月・上旬／中旬／下旬」を設定できます。登録した予定時期は一覧に表示されるので、取引予定を確認しやすくなります。

商品が手元に届いたら長期設定を解除することで、そのまま通常のお取引として引き続き管理できます。

7バックアップ・データ移行

画面下部の「書き出し」から登録データをファイルに保存できます。「読み込み」では、書き出しておいたデータをブラウザへ戻せます。

ブラウザのサイトデータを削除する前や、機種変更の前にはバックアップをおすすめします。

⚠️ ご利用上の注意

ブラウザのサイトデータを削除すると、お取引ノートの保存データも消えます。大切なデータは定期的に「書き出し」でバックアップしてください。
